# Security Operations Center

Este repositório reúne investigações sobre atividades maliciosas e ameaças digitais, com foco na identificação de comportamentos suspeitos, análise de evidências e avaliação de possíveis impactos aos usuários.

Cada caso é documentado a partir de uma abordagem investigativa, explorando os indícios disponíveis, os riscos identificados e as possíveis medidas de detecção aplicáveis a um ambiente de segurança.
