# Cyber Threat Intelligence

Este repositório reúne investigações independentes, com foco na compreensão das técnicas utilizadas por agentes maliciosos, na análise de seus métodos de operação e na identificação de padrões relevantes para a produção de inteligência sobre ameaças.

Os casos exploram situações reais ou observadas, utilizando pesquisa, coleta de informações e análise de evidências para construir uma compreensão estruturada de cada ameaça.
